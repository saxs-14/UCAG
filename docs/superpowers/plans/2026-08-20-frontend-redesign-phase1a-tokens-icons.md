# Frontend Redesign — Phase 1a: Design Tokens & Icon System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the dead heading-font wiring, add a real shadow elevation scale, and
replace every emoji-as-icon in the two navigation bars with `lucide-react` SVG icons —
the foundation checkpoint the rest of the frontend redesign builds on.

**Architecture:** Pure token/presentational changes to `app/globals.css`,
`app/layout.tsx`, `components/NavBar.tsx`, `components/MobileNavBar.tsx`, and
`config/labels.ts`. No new components, no data/backend changes, no route changes.

**Tech Stack:** Next.js 15 (App Router), Tailwind CSS v4 (`@theme` tokens), TypeScript
strict, `lucide-react` (new dependency, this plan installs it).

## Global Constraints

- Next.js 15 App Router, TypeScript strict (`tsc --noEmit` clean) — CLAUDE.md Definition
  of Done #1.
- No hardcoded English strings in components — every user-facing string sources from
  `config/labels.ts` (`config/labels.ts` file header, "config over hardcode").
- No `NEXT_PUBLIC_` secrets introduced (n/a to this plan — no secrets touched).
- `npm run lint` and `npm run typecheck` clean before each task's commit.
- No emoji used as a structural/navigational icon anywhere touched by this plan (design
  spec `2026-08-20-frontend-redesign-design.md` §2).
- Preserve every existing accessibility affordance already in the touched files
  (`aria-current`, `min-h-10`/`min-h-11` touch targets, `sm:hidden` breakpoint,
  `pathname.startsWith("/admin")` exclusion in `MobileNavBar`) — this plan adds icons
  and fixes tokens, it does not remove existing behavior.

## Task 2: Load Lexend alongside Inter in the rich-fonts script

**Files:**
- Modify: `app/layout.tsx:13-22` (`RICH_FONTS_SCRIPT`)

**Interfaces:**
- Consumes: nothing new (same `data-rich-fonts` attribute mechanism already in place).
- Produces: when the rich-fonts script runs, both Inter and Lexend are fetched in one
  Google Fonts stylesheet request, so Task 1's `--font-display: "Lexend", ...` override
  actually has a loaded font to use instead of silently falling back.

- [ ] **Step 1: Update the font stylesheet URL in `RICH_FONTS_SCRIPT`**

Replace:

```js
const RICH_FONTS_SCRIPT = `try {
  var c = navigator.connection || navigator.mozConnection || navigator.webkitConnection;
  if (!c || !c.saveData) {
    document.documentElement.setAttribute('data-rich-fonts', 'true');
    var link = document.createElement('link');
    link.rel = 'stylesheet';
    link.href = 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap';
    document.head.appendChild(link);
  }
} catch (e) {}`;
```

With:

```js
const RICH_FONTS_SCRIPT = `try {

    link.rel = 'stylesheet';
```

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";
import { BadgeCheck, BarChart3, GraduationCap, Landmark, User, Wallet } from "lucide-react";
import { Logo } from "@/components/Logo";
import { LABELS } from "@/config/labels";
import { useAuth } from "@/components/auth/AuthProvider";
import type { CatalogStats } from "@/lib/catalog/getCatalogStats";

const PUBLIC_NAV_ITEMS = [
  { href: "/", label: LABELS.nav.calculator, icon: GraduationCap },
  { href: "/institutions", label: LABELS.nav.institutions, icon: Landmark },
  { href: "/bursaries", label: LABELS.nav.bursaries, icon: Wallet },
  { href: "/statistics", label: LABELS.nav.statistics, icon: BarChart3 },
] as const;

interface NavBarProps {
  stats: CatalogStats | null;
}

export function NavBar({ stats }: NavBarProps) {
  const pathname = usePathname();
  const { user, loading } = useAuth();
  const isLoggedIn = !!user && !user.isAnonymous;

  return (
    <header className="no-print brand-band border-b border-white/10 shadow-sm sticky top-0 z-40 backdrop-blur-md">
      <nav className="mx-auto flex w-full max-w-5xl flex-wrap items-center justify-between gap-x-6 gap-y-2 px-4 py-3 sm:px-8">

        <div className="flex flex-wrap items-center gap-1.5 text-sm font-medium">
          {PUBLIC_NAV_ITEMS.map(({ href, label, icon: Icon }) => {

            return (
              <Link
                key={href}
                href={href}
                aria-current={active ? "page" : undefined}
                className={`flex min-h-10 items-center gap-1.5 rounded-lg px-3 py-1.5 text-xs sm:text-sm font-semibold transition-all ${
                  active
                    ? "bg-teal-600 text-white shadow-sm"
                    : "text-white/85 hover:bg-white/10 hover:text-white"
                }`}
              >
                <Icon className="h-4 w-4" aria-hidden="true" />
                {label}
              </Link>
            );
          })}

          {!loading && (
            isLoggedIn ? (
              <Link
                href="/account"
                aria-current={pathname === "/account" ? "page" : undefined}
                className={`flex min-h-10 items-center gap-1.5 rounded-lg px-3 py-1.5 text-xs sm:text-sm font-semibold transition-all ${

                }`}
              >
                <User className="h-4 w-4" aria-hidden="true" />

                <Link

                >
                  Create Account
                </Link>
              </div>
            )
          )}
        </div>
      </nav>
    </header>
  );
}
```

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";
import { BookOpen, GraduationCap, Landmark, LogIn, User, Wallet } from "lucide-react";
import { useAuth } from "@/components/auth/AuthProvider";
import { LABELS } from "@/config/labels";

const GUEST_MOBILE_NAV_ITEMS = [
  { href: "/", label: "APS Calc", icon: GraduationCap },
  { href: "/institutions", label: LABELS.nav.institutions, icon: Landmark },
  { href: "/programmes", label: "Programmes", icon: BookOpen },
  { href: "/bursaries", label: "Bursaries", icon: Wallet },
  { href: "/login", label: "Sign In", icon: LogIn },
] as const;

const USER_MOBILE_NAV_ITEMS = [
  { href: "/", label: "APS Calc", icon: GraduationCap },
  { href: "/institutions", label: LABELS.nav.institutions, icon: Landmark },
  { href: "/programmes", label: "Programmes", icon: BookOpen },
  { href: "/bursaries", label: "Bursaries", icon: Wallet },
  { href: "/account", label: "Profile", icon: User },
] as const;

export function MobileNavBar() {
  const pathname = usePathname();
  const { user } = useAuth();
  const isLoggedIn = !!user && !user.isAnonymous;

  // Hide mobile navbar on admin pages
  if (pathname.startsWith("/admin")) return null;

  const navItems = isLoggedIn ? USER_MOBILE_NAV_ITEMS : GUEST_MOBILE_NAV_ITEMS;

  return (
    <nav aria-label="Mobile Bottom Navigation" className="no-print fixed bottom-0 left-0 right-0 z-50 flex items-center justify-around border-t border-line bg-paper-raised/95 py-2 backdrop-blur-md shadow-lg sm:hidden">
      {navItems.map(({ href, label, icon: Icon }) => {
        const active = pathname === href || (href !== "/" && pathname.startsWith(href));
        return (
          <Link
            key={href}
            href={href}
            aria-current={active ? "page" : undefined}
            className={`flex min-h-11 flex-col items-center justify-center gap-0.5 px-3 py-1 transition-transform active:scale-95 ${
              active ? "text-brand-teal font-extrabold" : "text-ink-soft hover:text-ink font-medium"
            }`}
          >
            <Icon className="h-5 w-5" aria-hidden="true" strokeWidth={active ? 2.5 : 2} />
            <span className="text-[10px] tracking-tight">{label}</span>
          </Link>
        );
      })}
    </nav>
  );
}
```

Note: `min-h-10` was `min-h-11` is a deliberate correctness fix, not a style
preference — the previous `px-3 py-1` with a text-lg emoji glyph landed under the 44px
minimum touch-target guideline; `min-h-11` (44px) brings it into compliance now that
the file is already being touched.
